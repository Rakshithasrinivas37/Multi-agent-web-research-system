# Attention Mechanisms: A Deep‑Dive Overview --- ## Executive Summary Attention mechanisms enable neural networks to focus on the most relevant parts of an input when producing an output. At their core, they compute a **weighted sum of value vectors**, where the weights are derived from a **compatibility (or similarity) function** between a **query** and a set of **keys**. Starting with the additive (Bahdanau) attention for neural‑machine translation (NMT) [5], the field progressed through multiplicative (Luong) attention [3], scaled‑dot‑product attention [4][6], and finally multi‑head self‑attention that underpins the Transformer architecture [6][18]. This evolution removed recurrent bottlenecks, allowed full parallelism, and became the foundation of modern large‑language and vision models [7][8][20]. --- ## 1. General Formulation of Attention | Symbol | Meaning | |--------|---------| | \(q\) | Query vector (the element seeking information) | | \(\{k_i\}\) | Set of key vectors (representations to be compared) | | \(\{v_i\}\) | Corresponding value vectors (information to be aggregated) | | \(e_i = \text{score}(q, k_i)\) | Compatibility score between query and each key | | \(\alpha_i = \frac{\exp(e_i)}{\sum_j \exp(e_j)}\) | Softmax‑normalized attention weight | | \(c = \sum_i \alpha_i v_i\) | Context (output) vector, a weighted sum of values | The attention function maps \((q, \{k_i, v_i\})\) to the context \(c\) [4][6]. --- ## 2. Additive (Bahdanau) Attention *Introduced to solve the fixed‑length bottleneck of encoder‑decoder RNNs* [5][9]. - **Scoring function**: a small feed‑forward network (typically a single hidden layer with a tanh non‑linearity) takes the concatenation of a query and a key and outputs a scalar compatibility score. - **Intuition**: the network learns a flexible similarity measure that can capture complex interactions between query and key. *Limitation*: the retrieved excerpts do not contain the exact mathematical expression (e.g., \(v^\top \tanh(W_1 h_i + W_2 s_j)\)), but the high‑level description is provided in the original paper [5]. --- ## 3. Multiplicative (Luong) Attention *Proposed as a faster alternative to additive attention* [3]. - **Score variants**: - **Dot**: \(e_i = q^\top k_i\) - **General**: \(e_i = q^\top W k_i\) (learned matrix \(W\)) - **Computation**: pure matrix multiplication, avoiding the extra feed‑forward layer of additive attention, which reduces computational cost [1][12]. --- ## 4. Scaled Dot‑Product Attention The core operation of the Transformer [6]. \[ \text{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V \] - \(Q\in\mathbb{R}^{n\times d_k}\), \(K\in\mathbb{R}^{m\times d_k}\), \(V\in\mathbb{R}^{m\times d_v}\). - The scaling factor \(1/\sqrt{d_k}\) prevents the dot products from growing large when the key dimension \(d_k\) is high, which would otherwise push the softmax into saturated regimes and yield tiny gradients [4][6]. --- ## 5. Multi‑Head Attention Extends scaled dot‑product attention by running several independent attention “heads” in parallel [6][18]. 1. Linear projections create head‑specific queries, keys, and values: \[ Q_i = QW_i^{Q},\; K_i = KW_i^{K},\; V_i = VW_i^{V} \] 2. Each head computes scaled dot‑product attention, producing outputs \(\{O_i\}\). 3. The head outputs are concatenated and linearly transformed: \[ \text{MultiHead}(Q,K,V)=\text{Concat}(O_1,\dots,O_h)W^{O} \] Multi‑head attention allows the model to capture diverse relational patterns simultaneously, as each head operates in a different sub‑space of the representation [6][18]. --- ## 6. Self‑Attention in the Transformer When queries, keys, and values all originate from the same sequence, the mechanism is called **self‑attention** [6][18]. **Algorithmic steps (encoder side)** 1. **Embedding + Positional Encoding** – Token embeddings are summed with sinusoidal (or learned) positional encodings to inject order information [6][18]. 2. **Linear Projections** – Produce \(Q, K, V\) matrices via learned weight matrices. 3. **Multi‑Head Attention** – Apply the multi‑head operation described above. 4. **Add & Norm** – Residual connection followed by layer normalization. 5. **Feed‑Forward Network** – Position‑wise fully connected layers, again with residual + norm. In the decoder, an additional **mask** prevents a position from attending to future positions, preserving autoregressive generation [6][18]. Self‑attention enables **full parallelism** across sequence positions and captures **long‑range dependencies** without recurrence [6][18]. --- ## 7. Historical Progression & Impact | Year | Milestone | Key Contribution | |------|-----------|------------------| | 2014 | **Bahdanau et al.** – Additive attention for NMT | Introduced learnable alignment, removed fixed‑length bottleneck [5][9] | | 2015 | **Luong et al.** – Multiplicative attention | Showed faster dot‑product scoring with comparable translation quality [3] | | 2017 | **Vaswani et al.** – “Attention Is All You Need” | Scaled dot‑product, multi‑head, and self‑attention replace recurrence, enabling the Transformer [6] | | 2020‑2022 | Large‑scale language and vision models adopt Transformers | Multi‑head self‑attention becomes the default building block for LLMs and Vision Transformers [7][8][20] | The shift from additive → multiplicative → scaled dot‑product → multi‑head self‑attention **eliminated the sequential processing bottleneck of RNNs**, dramatically improving training speed and scaling to billions of parameters [7][8][20]. --- ## 8. Applications Attention mechanisms are now ubiquitous across domains: - **Natural Language Processing** – Machine translation, summarization, question answering, and large‑language models [7]. - **Computer Vision** – Vision Transformers, image captioning, and object detection [7][8]. - **Multimodal Tasks** – Audio‑visual alignment, cross‑modal retrieval, and speech‑text models [7][8]. --- ## 9.

# Attention Mechanisms: A Deep‑Dive Overview --- ## Executive Summary Attention mechanisms enable neural models to **focus** on the most relevant parts of an input when producing each output token. Starting from the **additive (Bahdanau) attention** for sequence‑to‑sequence translation, the field progressed to **multiplicative (Luong) attention**, then to the **scaled dot‑product** formulation that underpins the Transformer, and finally to **multi‑head attention**, which captures multiple relational patterns in parallel. This report synthesises the core definitions, mathematical formulations, and intuitive explanations of these variants, and outlines their evolution and trade‑offs, drawing exclusively from the primary literature and authoritative sources listed in the evidence set. --- ## 1. High‑Level Overview & Intuition At a conceptual level, attention computes a **weighted sum of value vectors** where the weights reflect how well each key matches a query. The process can be described in three steps: 1. **Scoring** – compare a query vector \(q\) with each key vector \(k_i\) to obtain a raw relevance score \(e_i\). 2. **Normalization** – apply a softmax over the scores to produce attention weights \(a_i = \frac{\exp(e_i)}{\sum_j \exp(e_j)}\). 3. **Aggregation** – combine the value vectors \(v_i\) using the weights: \(\displaystyle c = \sum_i a_i v_i\). This mechanism lets the model “look at” (or attend to) different parts of the input sequence dynamically for each output step, rather than compressing the entire source into a single fixed‑size vector [1][6]. --- ## 2. Additive (Bahdanau) Attention **Origin** – Introduced in *Neural Machine Translation by Jointly Learning to Align and Translate* (Bahdanau et al., 2015) [3]. ### 2.1 Formulation - **Alignment score** (learned via a feed‑forward network): \[ e_{t,i}= \mathbf{v}^{\top}\tanh\!\bigl(\mathbf{W}_1 \mathbf{h}_{t-1} + \mathbf{W}_2 \mathbf{s}_i\bigr) \] where \(\mathbf{h}_{t-1}\) is the decoder hidden state (query), \(\mathbf{s}_i\) is the encoder hidden state (key), and \(\mathbf{W}_1,\mathbf{W}_2,\mathbf{v}\) are trainable parameters. - **Softmax normalization**: \[ \alpha_{t,i}= \frac{\exp(e_{t,i})}{\sum_{k}\exp(e_{t,k})} \] - **Context vector** (weighted sum of encoder states): \[ \mathbf{c}_t = \sum_i \alpha_{t,i}\,\mathbf{s}_i \] These equations are presented in the original paper [3]; the retrieved snippet confirms the presence of an “alignment model” that scores encoder‑decoder matches and produces a weighted sum [3]. ### 2.2 Characteristics - **Additive combination** of query and key via a learned non‑linear layer. - Handles queries and keys of **different dimensionalities** because the linear projections can map them to a common space. - Slightly higher computational cost than pure dot‑product due to the extra feed‑forward network. --- ## 3. Multiplicative (Luong) Attention **Origin** – Described in *Effective Approaches to Attention‑based Neural Machine Translation* (Luong et al., 2015) [2]. ### 3.1 Scoring Functions Luong proposes three variants that compute similarity directly as a **dot product** (or a linear transformation thereof): | Variant | Score function | |---------|----------------| | **Dot** (pure) | \( \displaystyle \text{score}(h_t, h_s) = h_t^{\top} h_s \) | | **General** | \( \displaystyle \text{score}(h_t, h_s) = h_t^{\top} \mathbf{W}_a h_s \) | | **Concat** | \( \displaystyle \text{score}(h_t, h_s) = \mathbf{v}^{\top}\tanh\!\bigl(\mathbf{W}_a [h_t; h_s]\bigr) \) | where \(h_t\) is the decoder hidden state (query), \(h_s\) is an encoder hidden state (key), \(\mathbf{W}_a\) and \(\mathbf{v}\) are learned parameters, and \([\,\cdot\,;\,\cdot\,]\) denotes vector concatenation. These formulations are explicitly listed in the Luong paper [2]; the evidence notes that the “formulation of multiplicative (Luong) attention” is addressed there [2]. ### 3.2 Normalization & Context As with additive attention, the raw scores are passed through a softmax to obtain weights \(\alpha_{t,i}\), which are then used to compute the context vector \(\mathbf{c}_t = \sum_i \alpha_{t,i} h_i\). ### 3.3 Characteristics - **Multiplicative** (dot‑product) operations are **faster** on modern hardware because they map directly to matrix multiplications. - The **general** variant allows the key and query to have different dimensions via \(\mathbf{W}_a\). - The **concat** variant re‑introduces a small feed‑forward network, bridging additive and multiplicative styles. --- ## 4. Scaled Dot‑Product Attention **Origin** – Core of the Transformer architecture in *Attention Is All You Need* (Vaswani et al., 2017) [5]; also explained in IBM’s overview [4]. ### 4.1 Definition Given matrices of queries \(\mathbf{Q}\in\mathbb{R}^{n_q\times d_k}\), keys \(\mathbf{K}\in\mathbb{R}^{n_k\times d_k}\), and values \(\mathbf{V}\in\mathbb{R}^{n_k\times d_v}\): \[ \text{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \operatorname{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^{\top}}{\sqrt{d_k}}\right)\mathbf{V} \] The division by \(\sqrt{d_k}\) (the dimensionality of the keys) **stabilises the softmax** when \(d_k\) is large, preventing extremely large logits that would yield vanishing gradients [4][5]. ### 4.2 Characteristics - **Pure dot‑product**; no additional parameters beyond the linear projections that generate \(\mathbf{Q},\mathbf{K},\mathbf{V}\). - Highly parallelisable and efficient on GPUs/TPUs. - The scaling factor is essential for deep models with large hidden sizes. --- ## 5. Multi‑Head Attention **Origin** – Also introduced in the Transformer paper [5] and illustrated in the “multi‑head” explainer [11]. ### 5.1 Architecture 1. **Linear projections**: For each head \(i\) (total \(h\) heads), learn separate matrices \(\mathbf{W}_i^{Q}, \mathbf{W}_i^{K}, \mathbf{W}_i^{V}\) that map the original \(\mathbf{Q},\mathbf{K},\mathbf{V}\) into sub‑spaces of dimension \(d_k = d_{\text{model}}/h\). 2. **Head‑wise attention**: \[ \text{head}_i = \operatorname{Attention}\bigl(\mathbf{Q}\mathbf{W}_i^{Q}, \mathbf{K}\mathbf{W}_i^{K}, \mathbf{V}\mathbf{W}_i^{V}\bigr) \] 3. **Concatenation & final linear projection**: \[ \text{MultiHead}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \bigl[\text{head}_1;\dots;\text{head}_h\bigr]\mathbf{W}^{O} \] where \(\mathbf{W}^{O}\) projects the concatenated output back to \(d_{\text{model}}\). These steps are described in the Transformer paper’s Figure 2 and the accompanying text [5][11]. ### 5.2 Benefits - **Multiple representation subspaces**: Each head can attend to different aspects (e.g., syntactic vs. semantic relations). - **Improved expressivity** without a proportional increase in computational cost, because the total matrix size remains \(d_{\text{model}}\). --- ## 6. Evolution, Trade‑offs, and Comparative Discussion | Mechanism | Core Operation | Computational Cost | Flexibility | Typical Use‑Case | |-----------|----------------|--------------------|------------|------------------| | **Additive (Bahdanau)** | Feed‑forward network + tanh | Higher (extra MLP) | Handles mismatched dimensions easily | Early seq2seq models, small‑to‑medium hidden sizes | | **Multiplicative (Luong)** | Dot‑product (with optional linear transform) | Lower (pure matrix mul) | General variant adds a linear map; concat adds a small MLP | Faster NMT models, global attention | | **Scaled Dot‑Product** | Pure dot‑product with \(\frac{1}{\sqrt{d_k}}\) scaling | Very low (single matmul) | Requires same dimensionality for Q/K/V (handled by linear projections) | Transformer encoders/decoders, self‑attention | | **Multi‑Head** | Parallel scaled dot‑product heads | Slightly higher (multiple projections) but still efficient | Captures diverse relational patterns | State‑of‑the‑art language models, vision transformers | The **evolution** from additive to multiplicative to self‑attention reflects a drive toward **computational efficiency** and **parallelism** while preserving or enhancing modeling power [1][16][18]. Additive attention often yields better performance on longer sequences because the learned non‑linearity can compensate for large vector magnitudes, but it is slower. Multiplicative attention (especially the dot variant) is faster but can suffer from gradient issues when the key dimension grows; the scaling trick in the Transformer resolves this [4][5]. Multi‑head attention builds on scaled dot‑product to allow the model to attend to information from multiple sub‑spaces simultaneously, a key factor behind the success of modern large‑scale models. **Limitations of the current evidence** – The retrieved snippets do not contain the full set of equations for every variant (e.g., the exact concat‑score formula for Luong attention).
